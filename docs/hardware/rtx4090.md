# RTX 4090 (sm_89)

This fork runs Inkling 2 Mini on one GeForce RTX 4090. Everything below was measured on one
machine on 2026-11-26; treat it as one data point, not a general guarantee.

| Item | Value |
|---|---|
| GPU | RTX 4090, 24 GB, compute capability 8.9, 128 SMs, 72 MB L2, 99 KB opt-in shared memory per block |
| Host link | PCIe Gen3 x16 |
| Driver | 610.57.04 (CUDA 13.3 driver API), unchanged by the build |
| Toolkit | CUDA 12.8.93 (`nvcc`), installed in a user directory |
| Model | unsloth `Mainline_Support/Inkling-2-Mini-UD-Q4_K_XL.gguf` (NVFP4 ×40, Q8_0 ×154, F32 ×518, BF16 ×32) |
| Draft | `mtp.safetensors` of the native Inkling 2 Mini checkpoint (DSpark, 0.56 GB) |

## Build

```bash
ASTRAL_CUDA_ARCHS=89 NVCC=/path/to/cuda-12.8/bin/nvcc cargo build --release
./target/release/astral hw        # profile sm89, kernel family f80
./target/release/astral selftest  # 80 / 80
```

The toolkit does not need root or a driver change. One way that keeps the driver untouched
is a conda prefix with only the compiler packages:

```bash
conda create -p $HOME/cuda-12.8 --override-channels --strict-channel-priority \
  -c nvidia/label/cuda-12.8.1 -c conda-forge \
  cuda-nvcc cuda-cudart-dev cuda-nvrtc-dev cuda-cccl libcublas-dev cuda-cuobjdump cuda-nvdisasm cuda-profiler-api
```

Do not use the NVIDIA runfile installer or the distribution's `cuda` / `cuda-drivers` packages for
this: both can replace the driver. Do not put the toolkit's `lib/stubs` on `LD_LIBRARY_PATH`; the
stub `libcuda` would shadow the real driver at run time.

## What differs from Hopper

- **Profile.** `ArchProfile::Sm89` maps to the F80 kernel family (`mma.sync` + `cp.async`), with
  FP8 tensor cores reported but not used and no FP4 path.
- **No programmatic dependent launch** (compute capability below 9.0) and **no wgmma** (Hopper
  only). Inkling prefill GEMMs take the `mma3` path; the `mma5` fragment kernels are not wired
  into the Inkling model.
- **Context.** The Inkling path is capped at 8,192 tokens (`MAX_CTX` and several
  `min(capacity, MAX_CTX)` limits), with KV allocated for all 48 slots at full capacity.

## Fix found on this GPU

`DeviceBuffer::zeroed`, `DeviceBuffer::copy_from_slice` and `VmmRegion::write` queue a memset or a
pageable host-to-device copy on the legacy default stream and could return before it
completed, while Astral's streams are `CU_STREAM_NON_BLOCKING`. A kernel launched right after
could read a half-copied input or have its output zeroed. On this PCIe Gen3 machine the
self-test failed 3–4 MXFP4 cases with partly zero outputs that changed from run to run. The
helpers now wait for the legacy stream before returning (commit `d17a519`). The bug is not
specific to sm_89.

## Validation against llama.cpp

Reference: llama.cpp b12751 (`532d674`) on the same GGUF. Tools and commands:
[bench/llamacpp_compare](../../bench/llamacpp_compare/README.md).

| Check | Result |
|---|---|
| Kernel self-test | 80 / 80, three runs |
| Tensor table | type counts and byte totals match the file; no padding |
| Tokenizer | 16 chat prompts: Astral `/tokenize` equals llama-server `/apply-template` + `/tokenize`; 10 mixed-script strings: `llama-tokenize` equals `tokenizer.json` |
| `verify-model` | PASS on all 48 slots (largest `l_out` max abs diff 0.43, `result_output` 0.06) |
| KL divergence, decode path (c512 × 8 chunks, 2,040 positions) | mean 0.00180, p99 0.0228; llama.cpp's own `-ub 512` vs `-ub 1`: mean 0.00201, p99 0.0284 |
| Top-1 agreement where the reference margin ≥ 0.5 | 99.94% (1 of 1,754 positions differs, margin 0.84) |
| Greedy, 16 prompts | every first divergence is at a near-tie (reference margin < 0.5) |
| Teacher-forced, 16 × 500 positions | 94 argmax differences, all with margin ≤ 0.58 |
| Batched prefill vs token-by-token (16 prompts, last position) | argmax equal on all 16; near-top raw-logit diff up to 1.18, KL(step‖prefill) up to 0.0147; no threshold in matching units has been calibrated yet |
| DSpark speculative vs plain greedy (16 prompts, teacher-forced) | 0–15 differing positions per prompt, all within 0.61 logit |

Perplexity on the llama.cpp-docs corpus (c512): llama.cpp 3.5352, Astral 3.5359.

## Performance

See [Inkling 2 Mini on RTX 4090](../benchmarks/inkling2_mini_rtx4090.md): 143.1 tok/s without a draft
and 173.9 tok/s with DSpark, 1.92× llama.cpp on the same file.
